# 커뮤니티 메뉴 복원

현재 메뉴 복원 배포에서는 기존 이메일 로그인을 유지합니다. Google 로그인 제공업체의 지원 이메일 설정 완료 후 `GOOGLE_SIGNIN_ENABLED=true`로 Google 화면을 활성화합니다. 공통 알림 동작은 [공통 팝업](common-popups.md)을 참고하세요.

## 접속 주소

`https://gaebal2.github.io/koinkorae/`를 사용합니다. `gaebla2`는 다른 계정 이름이므로 이 저장소의 Pages 주소가 아닙니다.

## 복원 범위

- 기본 첫 화면은 홈, 메뉴는 홈·지도·체크인·프로필.
- Google 로그인 팝업과 계정 선택. 이메일/비밀번호 입력 화면 제거.
- 유저/코인 피드가 같은 정렬·기간 상태를 사용합니다. 다른 메뉴를 방문해도 현재 선택을 유지합니다.
- 피드 작성·조회·본인 삭제, 댓글 작성·조회, 프로필에서 팔로우와 취소.
- 출석은 한국 시간(UTC+9) 하루 1회 10 BP. Firestore 서버 요청 시간을 기준으로 규칙을 검사하고 트랜잭션으로 중복 지급을 차단합니다. 클라이언트 시계를 바꿔도 임의 날짜의 BP를 받을 수 없습니다.
- 지도·거래·프로필 및 보라색 아이콘은 유지합니다. 거래는 무료 3개 한도를 유지합니다.

## 아직 온라인으로 제공하지 않는 기능

배틀 점수 검증, BP 사용, 광고 보상, 리포스트와 전체 PRD 활동 프로필은 로컬 서버 구현을 온라인 환경으로 옮기는 후속 범위입니다. 배틀·광고는 준비 중으로 표시하며 임의의 클라이언트 점수/보상을 저장하지 않습니다. Firebase 새 게시물은 지지·반대 0점으로 시작하고 클라이언트는 점수를 변경할 수 없습니다. 현재 정렬은 조회한 게시물의 저장된 점수를 사용합니다. PRD의 기간별 배틀 이벤트 집계와 급상승 계산은 배틀 서버 연결 시 적용해야 합니다. 홈 조회는 최신 300개, 댓글은 처음 100개 범위입니다.

## 인증 설정

Firebase Authentication의 Google 제공업체를 활성화하고 프로젝트 공개 이름과 지원 이메일을 지정합니다. 승인된 도메인에는 `gaebal2.github.io`, `localhost`가 있습니다. GitHub Pages에서 타사 저장소 제한 때문에 redirect 복귀가 실패하는 경우를 피하기 위해 클릭 즉시 `signInWithPopup`을 호출합니다. 차단·취소·네트워크 오류를 한국어로 안내합니다. 앱 내 브라우저는 Chrome/Safari에서 열도록 안내합니다. Google 계정 로그인 완료는 실제 사용자 계정으로 확인해야 합니다.

## 검증

`npm test`에 피드 전환·정렬·기간 테스트를 포함합니다. `firebase emulators:exec --only firestore --project demo-koinkorae "node --test tests/firestore.test.js"`는 기존 지도 규칙 외에 BP 조작·중복 지급, 피드 점수/작성자 조작, 댓글과 팔로잉 권한을 검사합니다.
