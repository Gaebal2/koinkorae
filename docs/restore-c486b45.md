# c486b45 기능 복원

기준: `c486b45d6e1f5f65206cba97343e82423ff44ac7`. 현재 Firebase 앱 위에 기능을 통합하며 이전 데모 앱으로 되돌리지 않습니다.

## 적용

- 홈: 지지·반대 막대, 코인별 노출 순위, 정렬별 코인 집계, 실제 댓글 수, 리포스트/취소, 공통 팝업 사진 확대.
- 프로필: 실제 팔로워/팔로잉/맞팔 친구, 사용자 프로필 이동 및 팔로우, 작성 피드와 리포스트 탭, 본인 댓글 원문 조회, PIN 상세/사진/수정/삭제/지도 이동, 본인 BP 등급과 다음 등급 진행률.
- 지도: 코인별 이미지 마커, 상세창의 본인 PIN 삭제, 등록창의 브라우저 뒤로가기 닫기.
- 공통 피드 카드를 사용하므로 홈과 프로필의 댓글, 리포스트, 배틀, 본인 삭제 동작이 같습니다.

## 기존 기능 보존

Google 로그인, Firebase 저장, 프로필 편집, 홈/지도/체크인/프로필 메뉴, 출석, 피드 정렬 상태 유지, 보라색 디자인과 투명 아이콘, PI/SL/PSL 우선 목록, 작은 이미지 추가 버튼, 코인 우측 정렬, 두 랜덤 게임을 유지합니다. PIN은 기존과 같이 등급에 관계없이 무료 3개입니다.

이전 커밋의 샘플 회원/핀/댓글 및 임의 배틀 점수는 운영 데이터로 옮기지 않습니다. 배틀은 현재 무료 연습 게임을 유지하며 지지/반대 점수와 BP는 클라이언트 게임 결과로 변경하지 않습니다. 옛 등급별 PIN 제한/1 BP 차감도 현재 무료 정책으로 대체합니다.

## 데이터와 접근 권한

- 기존 `profiles/{uid}/following/{target}`를 그대로 사용합니다. 공개 소셜 프로필에 팔로워/팔로잉/맞팔을 표시하도록 관계를 공개 조회하며 변경은 본인만 가능합니다.
- `posts/{postId}/reposts/{uid}`에 계정별 단일 참조를 저장합니다. 삭제된 원문은 프로필에 표시하지 않습니다. 재게시로 홈 피드를 복제하지 않습니다.
- 본인 댓글은 authorId로 collection-group 조회하고 살아 있는 원문만 표시합니다. 해당 쿼리용 인덱스를 함께 배포합니다.
- 작성 피드와 리포스트, 내 댓글은 홈의 최신 300개 제한에 종속되지 않습니다. 홈 순위와 코인 집계는 기존대로 조회한 최신 300개 범위, 댓글 대화창은 최초 100개 범위입니다.
- 공개 목록에는 이메일/인증정보/다른 사용자의 BP 잔액을 포함하지 않습니다.

## 검증

일반 테스트에 코인 순위 합산, 실제 맞팔 관계, 등급 경계 테스트를 추가했습니다. Firestore 에뮬레이터에서 기존 PIN/출석/피드 권한과 함께 리포스트 생성·중복·타인 삭제·점수 변조 차단, 기존 팔로우 데이터 조회, 본인 댓글 조회 권한을 검사합니다.

모바일 390px 미리보기에서 프로필 탭, 리포스트, 맞팔 해제 후 수 갱신, 내 댓글, PIN 마커/삭제 확인창/취소, 등록창 및 프로필 목록 뒤로가기를 확인했습니다. 미리보기 데이터는 운영 Firebase에 저장하지 않습니다.
